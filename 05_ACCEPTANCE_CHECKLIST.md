# JIMON — ACCEPTANCE CHECKLIST

## Утверждённые первые экраны
- [ ] Главный экран соответствует `01_APPROVED_UI_3_SCREENS.png`.
- [ ] На главном только две роли: Новичок / Партнёр.
- [ ] На главном нет уровней скидки.
- [ ] Новичок стартует с 0% и 0 ¥.

## Партнёр
- [ ] Уровни только 10/20/30/40/50/60.
- [ ] 0% отсутствует.
- [ ] Есть поле текущего накопленного товарооборота.
- [ ] Есть `Не помню товарооборот`.
- [ ] При неизвестном обороте автоматическое повышение скидки отключено.
- [ ] Не используется формулировка `Возможный уровень скидки` для текущей скидки.
- [ ] После сохранения данные сворачиваются в компактную строку.
- [ ] Есть действие `Изменить`.

## Каталог
- [ ] Есть поиск по названию.
- [ ] Тип: Все / Единичные / Комплекты.
- [ ] Направление: Все / Красота / Здоровье.
- [ ] Слова `Для тела` в каталоге нет.
- [ ] Все кнопки одного ряда одинакового размера.
- [ ] Активная кнопка насыщенно зелёная.
- [ ] Неактивные кнопки светло-зелёные и визуально кликабельные.
- [ ] Фильтры комбинируются.
- [ ] Переключение фильтров не очищает план.
- [ ] На карточке одна актуальная цена.
- [ ] Есть фото, русское и китайское название.
- [ ] Есть `Добавить в план`.
- [ ] Есть постоянная кнопка `План покупок · N`.

## Категории
- [ ] Используются только `Красота` / `Здоровье`.
- [ ] Комплекты наследуют категорию базового товара.
- [ ] Распределение соответствует `07_CATEGORY_MAPPING.md`.

## Расчёт
- [ ] Пороги: 331/1503/5800/22000/220000/660000 ¥.
- [ ] Текущий заказ считается по скидке, доступной до заказа.
- [ ] Новый уровень начинает действовать со следующего отдельного заказа.
- [ ] Один товар/позиция = один заказ.
- [ ] Разные товары не объединяются.
- [ ] Фактические цены берутся из данных.
- [ ] Никаких выдуманных цен 50/60%.

## Курьер
- [ ] UI использует `Услуги курьера`.
- [ ] Нет термина `Доставка до склада`.
- [ ] Стоимость не захардкожена как 12 ¥.
- [ ] Курьер входит в `К оплате`.

## Итог
- [ ] Каждый заказ имеет отдельный итог.
- [ ] Есть `Итого к оплате`.
- [ ] Есть `Экономия благодаря скидке`.
- [ ] Есть `Ваш уровень для следующих покупок`.
- [ ] Общая сумма курьерских услуг не дублируется отдельной строкой.
