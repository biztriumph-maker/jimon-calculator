## Критические правила
- Новичок стартует с 0% и 0 ¥ накопленного товарооборота.
- Партнёр не выбирает 0%. Допустимые уровни: 10/20/30/40/50/60%.
- Для партнёра запрашиваются:
  - текущий уровень скидки;
  - текущий накопленный товарооборот.
- Если партнёр не помнит товарооборот, расчёт выполняется только в пределах выбранной действующей скидки; автоматический переход на следующий уровень не рассчитывается.
- Скидка, полученная текущим заказом, действует начиная со следующего отдельного заказа в текущем плане.
- Один товар/одна товарная позиция = отдельный заказ.
- В интерфейсе использовать термин `Услуги курьера`.
- Направления каталога: только `Красота` и `Здоровье`.


## Утверждённые визуалы текущей версии

- `01_APPROVED_UI_3_SCREENS.png` — утверждённые первые три экрана:
  1. главный экран;
  2. экран новичка;
  3. экран партнёра.
- `08_APPROVED_CATALOG.png` — утверждённый внешний вид каталога.
- `09_APPROVED_PARTNER_MODAL.png` — утверждённое модальное окно партнёра.

Для каталога зафиксировано:
- Тип товара: `Все / Единичные / Комплекты`
- Направление: `Все / Красота / Здоровье`
- Активная кнопка насыщенно-зелёная.
- Неактивные кнопки светло-зелёные и явно кликабельные.
- После ввода данных партнёра они сворачиваются в компактную строку.
- Постоянная нижняя кнопка: `План покупок · N`.

Для модального окна партнёра зафиксировано:
- скидки только 10/20/30/40/50/60%;
- ввод текущего накопленного товарооборота;
- опция `Не помню товарооборот`;
- при неизвестном обороте расчёт идёт только в пределах выбранной действующей скидки;
- автоматический переход на следующий уровень в этом режиме не рассчитывается.
