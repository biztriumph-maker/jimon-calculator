# 12 — ПЛАН ПОКУПОК И ФИНАЛЬНАЯ ЛОГИКА РАСЧЁТА

Статус: утверждено для первой рабочей версии.

## 1. Товарооборот

Товарооборот считается ТОЛЬКО по розничной цене каталога.

Формула для каждой позиции:
`товарооборот позиции = розничная цена каталога × количество`

В товарооборот НЕ входят:
- скидка;
- фактическая сумма оплаты после скидки;
- услуги курьера.

Пример:
- цена каталога 319 ¥;
- количество 2;
- товарооборот позиции = 638 ¥;
- если применяется скидка 10%, оплачиваемая цена товара может быть 558 ¥;
- товарооборот всё равно увеличивается на 638 ¥.

## 2. Когда меняется скидка

Пороги:
- 0 ¥ → 0%
- 331 ¥ → 10%
- 1 503 ¥ → 20%
- 5 800 ¥ → 30%
- 22 000 ¥ → 40%
- 220 000 ¥ → 50%
- 660 000 ¥ → 60%

Правило:
- текущий заказ рассчитывается по уровню скидки, который действовал ДО него;
- после заказа в накопленный товарооборот добавляется розничная стоимость каталога × количество;
- если достигнут новый порог, новый уровень действует только со СЛЕДУЮЩЕГО отдельного заказа.

## 3. Новичок

Старт:
- скидка 0%;
- товарооборот 0 ¥.

Система сама последовательно пересчитывает доступный уровень между заказами.

## 4. Партнёр

Партнёр выбирает:
- текущую скидку: 10/20/30/40/50/60%;
- текущий накопленный товарооборот.

0% партнёру не показывать.

Если выбран вариант `Не помню товарооборот`:
- цены считаются по выбранной действующей скидке;
- автоматический переход на следующий уровень не рассчитывается.

## 5. Один заказ

Разные товары не объединяются в один заказ.

Один заказ = одно наименование товара, при этом количество может быть больше 1.

### Единичный товар
Для первой версии:
- количество 1–5 штук одного наименования в одном заказе;
- услуги курьера = 12 ¥ за весь такой заказ;
- не 12 ¥ за каждую штуку.

Если нужно больше 5 штук:
- автоматическое правило 12 ¥ не применять;
- показать, что условия курьера могут отличаться;
- в MVP не придумывать стоимость.

### Комплект
- каждый комплект считается отдельной единицей комплектного товара;
- услуги курьера = 12 ¥ за КАЖДЫЙ комплект;
- при количестве N: услуги курьера = `12 × N`.

## 6. Добавление товара

После нажатия `Добавить в план` открыть экран/панель добавления.

Показать:
- реальное фото товара;
- русское название;
- китайское название;
- цену каталога за 1 шт.;
- количество;
- применяемый уровень скидки;
- цену товара с учётом фактической магазинной цены данного уровня;
- услуги курьера;
- `К оплате`.

Для единичного товара:
`К оплате = цена со скидкой × количество + 12 ¥` при количестве 1–5.

Для комплекта:
`К оплате = цена комплекта со скидкой × количество + 12 ¥ × количество`.

## 7. План покупок

При нажатии `План покупок · N` открывается полноценный экран.

Каждая позиция показывается как отдельный заказ.

Карточка заказа:
- `Заказ №N`;
- реальное фото;
- русское название;
- китайское название;
- `Цена каталога`;
- `Количество`;
- `Применена скидка X%`;
- `Цена со скидкой`;
- `Услуги курьера`;
- `К оплате`;
- `Изменить`;
- `Удалить`.

### Перестановка заказов
Порядок влияет на применяемую скидку, поэтому при изменении порядка весь план пересчитывается.

Стрелки:
- первая позиция: только `↓`;
- средняя позиция: `↑` и `↓`;
- последняя позиция: только `↑`;
- если позиция одна — стрелки не показывать.

Не показывать неработающую стрелку серой иконкой, если можно просто не показывать её.

## 8. Итог плана

Показать:
- `Итого к оплате`;
- `Экономия благодаря скидке`;
- `Ваш уровень для следующих покупок: X%`.

Услуги курьера могут быть показаны в общем итоге как справочная сумма, но они НЕ входят в товарооборот.

## 9. Акции

Акционные позиции и временные предложения:
- НЕ включать в каталог;
- НЕ учитывать в автоматической логике;
- пользователь отслеживает акции самостоятельно.

Лист `Акции` из мастер-таблицы для первой версии приложения игнорировать.

## 10. Фото

Фото товара:
- только из актуальных скриншотов интернет-магазина, присланных владельцем;
- не генерировать упаковки ИИ;
- не менять геометрию, цвет и форму упаковки;
- один и тот же товар должен иметь одно и то же изображение во всех экранах.

PDF-каталоги используются только для привычных русских названий/формулировок.
